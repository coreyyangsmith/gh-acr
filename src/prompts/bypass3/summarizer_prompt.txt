## Schema Specification

### Root
The root is a **JSON object** containing exactly these two keys:
1. **`changes`** – **array** of one or more **change objects**.
2. **`likely_intent`** – **string** describing the inferred intent behind the set of changes.

---

### `changes` Array
- Must contain **one or more** objects.
- Each object **must** have these four required keys:

| Key            | Type     | Description |
|----------------|----------|-------------|
| **`type`**     | string   | The category of change. Common values: "addition", "modification", "removal". |
| **`location`** | string   | Where in the codebase or documentation the change occurred (e.g., "Parameter enum", "config.yaml"). |
| **`snippet`**  | string   | A short snippet (or placeholder "") showing the new or modified code/text. Must be enclosed in quotes and escaped per JSON rules. |
| **`description`** | string | A concise human-readable explanation of the change, including details like purpose, added values, or expected behavior. |

---

### `likely_intent` String
- A single sentence or short paragraph.
- Summarizes **why** the changes were made (the bigger picture), not just what they are.
- Should connect the changes in `changes` to their intended outcome.

---
