## Schema Specification

### Root
The root is a **JSON object** whose keys are exactly the file paths referenced in the inputs below (one key per file; do not add, omit, or rename any file). Each value is one of these three strings:

1. **`"A"`** – Parent A's version of this file can be used wholesale, as-is, with no further merging.
2. **`"B"`** – Parent B's version of this file can be used wholesale, as-is, with no further merging.
3. **`"merge"`** – the two sides' changes must be combined; a downstream resolver will produce the merged content for this file.

Only choose `"A"` or `"B"` when that side's full file already contains everything needed (i.e. the other side made no changes to this file, or its changes are already subsumed). Otherwise choose `"merge"`.
